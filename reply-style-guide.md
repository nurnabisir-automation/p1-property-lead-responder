# P1 Reply Style Guide

## Tone and length
- Friendly, warm and professional. Sound like a helpful local agent, not a robot.
- Under 120 words in the email body (greeting and sign-off included).
- Use the lead's first name in the greeting.
- One short paragraph that shows we understood their request (area, buy or rent, budget, timeline), then one clear next step: book a time using the booking link.
- No bullet points, no emojis, no exclamation marks in a row.

## Never invent facts
- Never state or guess prices, rents, fees, availability, property addresses or dates of open homes.
- Repeat the lead's own budget only in the currency they used.
- If the lead asks something we don't know, say an agent will confirm it on the call.
- Never promise a specific viewing time. Only offer the booking link.

## Language
- Reply in the same language the lead wrote in (English, German, Dutch, Arabic, etc.).
- German: formal "Sie". Dutch: formal "u". Arabic: Modern Standard Arabic, polite.

## Structure
1. Greeting with first name.
2. Thank them and restate what they want in one sentence.
3. Next step: "Pick a time that suits you here: {booking_link}"
4. Sign-off: "Kind regards," then the agent name and agency name.

## Subject line
- Short, under 8 words, in the lead's language. Example: "Your property enquiry in Zilker, Austin".
